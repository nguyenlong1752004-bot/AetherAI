# AetherAI

Website frontend demo cho một AI Workspace hiện đại.

## Tính năng

- Dashboard
- AI Chat demo
- Đăng ký / đăng nhập demo
- Quản lý dự án
- Analytics
- Thông báo
- Cài đặt
- Hồ sơ
- Dark / Light mode
- Responsive
- LocalStorage

## Chạy

Mở `index.html` bằng trình duyệt.

## GitHub Pages

Upload toàn bộ 3 file:

- `index.html`
- `style.css`
- `script.js`

Sau đó vào:

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

> Lưu ý: hệ thống đăng nhập trong bản này là frontend demo và dữ liệu được lưu bằng LocalStorage. Không sử dụng để lưu mật khẩu thật.
